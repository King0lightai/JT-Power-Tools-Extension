🔌 Other MCP Clients

Generic setup guide for any MCP-compatible client

Overview

The JT Power Tools MCP server is compatible with any client that supports the Model Context Protocol (MCP). This guide provides the technical details needed to connect any MCP client to your JobTread data.

What You'll Need

  • JT Power Tools Premium - Active subscription with MCP access
  • License Key - Your JT Power Tools license key
  • Grant Key - Your JobTread API grant key (from the API tab in the extension popup)
  • MCP-Compatible Client - Any application supporting MCP

Server Endpoints

Endpoint URL Purpose
SSE Endpoint https://mcp.jobtread-tools.pro/sse Server-Sent Events for real-time communication
Message Endpoint https://mcp.jobtread-tools.pro/message HTTP POST for sending messages
Health Check https://mcp.jobtread-tools.pro/health Server health status
Tools List https://mcp.jobtread-tools.pro/tools Available MCP tools

Authentication

All requests must include an Authorization header with a Bearer token. The token format is:

Authorization: Bearer LICENSE_KEY:GRANT_KEY

Where:

  • LICENSE_KEY - Your JT Power Tools premium license key
  • GRANT_KEY - Your JobTread API grant key
Security Note

Keep your keys secure. Never share them publicly or commit them to version control.

Standard MCP Configuration

For clients using the standard MCP JSON configuration format:

{ "mcpServers": { "jobtread": { "url": "https://mcp.jobtread-tools.pro/sse", "headers": { "Authorization": "Bearer YOUR_LICENSE_KEY:YOUR_GRANT_KEY" } } } }

Claude Desktop (via mcp-remote)

Claude Desktop only supports local stdio servers. Use mcp-remote as a bridge:

Step 1: Install mcp-remote

npm install -g mcp-remote

Step 2: Configure Claude Desktop

Add to ~/.claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows):

{ "jobtread": { "command": "npx", "args": [ "mcp-remote", "https://mcp.jobtread-tools.pro/sse", "--header", "Authorization: Bearer YOUR_LICENSE_KEY:YOUR_GRANT_KEY" ] } }

HTTP API Usage

For custom integrations, you can use the HTTP endpoints directly:

List Available Tools

curl -X GET "https://mcp.jobtread-tools.pro/tools" \ -H "Authorization: Bearer YOUR_LICENSE_KEY:YOUR_GRANT_KEY"

Call a Tool

curl -X POST "https://mcp.jobtread-tools.pro/message" \ -H "Authorization: Bearer YOUR_LICENSE_KEY:YOUR_GRANT_KEY" \ -H "Content-Type: application/json" \ -d '{ "method": "tools/call", "params": { "name": "jt_search", "arguments": { "query": "kitchen remodel" } } }'

Available Tools

The MCP server provides tools for reading, writing, and deleting your JobTread data — what a connection can do is set by its permission tier (Read, Write, or Delete). A few common ones:

Tool Name Description Access
jt_job_context Full job snapshot: budget, schedule, documents, comments, and daily logs in one call Read
jt_schedule_context Schedule items, tasks, time entries, and overdue/upcoming work Read
jt_crm_context Customers, vendors, subcontractors, contacts, and locations Read
jt_search Search across jobs, contacts, documents, and other records Read
jt_budget_compare Compare two budget backups and report what changed Read
jt_job_write Create, update, or delete jobs and job areas Write / Delete
jt_task_write Create, update, complete, or delete schedule tasks Write / Delete
jt_budget_write Add, edit, or remove budget line items and cost groups Write / Delete
jt_document_write Full lifecycle for invoices, bills, POs, change orders, and payments Write / Delete
jt_daily_log_write Post and edit daily logs Write
jt_comment_write Add comments to jobs and documents Write

Plus tools for contacts, time entries, dashboards, data views, workflows, webhooks, catalog items, bills, files, forms, notes, and email — 30+ in total. The complete, current list (with which tools your tier can use) is in the JT Power Tools extension → MCP tab.

Permission Tiers

Access is controlled by a three-tier permission model set per grant key: Read (view only), Write (create and update), and Delete (full read, write, and delete). An admin sets the tier in the JT Power Tools extension → MCP tab.

Testing the Connection

Use the health endpoint to verify your connection:

curl -X GET "https://mcp.jobtread-tools.pro/health"

Expected response:

{ "status": "healthy", "version": "1.0.0" }

Troubleshooting

401 Unauthorized

  • Check that your License Key is valid and active
  • Verify the Grant Key is correct
  • Ensure the Authorization header format is correct: Bearer LICENSE:GRANT

403 Forbidden

  • Your subscription may not include MCP access
  • Check your subscription tier supports the MCP feature

Connection Timeout

  • Verify the endpoint URL is correct
  • Check your network connection
  • Try the health endpoint to verify server status

Empty Results

  • Verify your Grant Key has the necessary permissions in JobTread
  • Check that you have data in JobTread matching your query
  • Try regenerating your Grant Key in the API tab

Rate Limits

To ensure fair usage:

  • Requests per minute: 60
  • Concurrent connections: 5

If you exceed these limits, you'll receive a 429 (Too Many Requests) response.
