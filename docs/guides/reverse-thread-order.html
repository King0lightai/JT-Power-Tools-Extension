Essential

Reverse thread order.

Newest comment at the top, oldest at the bottom — and the reply box right under the latest message instead of way down at the end of the thread.

Video walkthrough coming soon

What it does

By default JobTread comment threads run oldest-to-newest, with the reply field at the very bottom. On a long thread you scroll forever to read the most recent comment, then scroll again to reply. This flips the order: newest message on top, reply box right where you're reading. Same data, way less scrolling.

Turn it on

  1. Click the JT Power Tools icon.
  2. Find Reverse Thread Order under Productivity Tools.
  3. Flip it on. Open any comment thread.

Good to know

  • Especially helpful on long client-facing threads where you only want to see the most recent reply.
  • Other features that work in threads (text formatter, message templates) keep working as normal.
