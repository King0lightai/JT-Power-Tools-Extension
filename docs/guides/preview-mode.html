Preview mode.

Click the eye icon and a live preview panel opens next to your text field. See bold, italic, tables, and color render in real-time as you type — before you save.

Video walkthrough coming soon

What it does

When you're using Text Formatter to write a long budget description or detailed daily log, it can be hard to picture how it'll look once saved. Preview Mode adds an eye icon to the formatter toolbar. Click it and a panel opens showing your text fully rendered, updating live as you type. Especially useful for tables, alerts, and color-coded notes.

Turn it on

  1. Make sure Text Formatter is on first — Preview Mode rides on top of it.
  2. Click the JT Power Tools icon.
  3. Find Preview Mode under Productivity Tools.
  4. Flip it on. Click into a text field that has the formatter toolbar.

How to use it

  1. Click the eye icon on the Text Formatter toolbar.
  2. The preview panel pops out next to your editor.
  3. Type and watch your formatting render. Adjust until it looks right.
  4. Click the eye again (or press Esc) to close the preview.

Good to know

  • Preview repositions itself automatically — right, left, below, or above — to stay visible as you scroll.
  • Best feature for tables. Building a clean table by feel is hard; with the preview you see it instantly.
