Pave Explorer.

See the JobTread API calls behind any page, live — read each request and response, then copy a clean, shareable version. Nothing ever leaves your browser.

Video walkthrough coming soon

What it does

Every page in JobTread runs on its Pave API. Pave Explorer is a live, read-only window into those calls: open the tab, click around JobTread, and the queries stream in as they fire. Click any one to read its Request, its Response, and a Shareable version with your keys stripped out — then copy whichever you need.

It's built for power users, developers, and anyone learning JobTread's API — to understand how a page loads, debug a workflow, or grab a real query as a starting point for automation or an MCP tool. Everything stays local in your browser. Nothing is uploaded.

Turn it on

  1. Click the JT Power Tools icon and open the Pave tab (Pro).
  2. For the best experience, run it as the side panel so it stays open while you work — set “Always open in side panel” on the Account tab.
  3. The tab streams live captures as soon as it's open. No reload needed.

How to use it

  1. Open Pave Explorer side-by-side with JobTread.
  2. Do something in JobTread — open a job, save a budget, load the schedule. The calls appear in the list, labeled as reads or mutations.
  3. Click a call to expand it, then copy the Request, Response, or the key-stripped Shareable query.

Good to know

  • Run it as the side panel — the popup closes the moment you click into JobTread, but the panel stays put while you act.
  • One JobTread action fires many calls (reads, polls, permission checks). The list labels mutations vs. reads so you can find the one that matters.
  • The Shareable view strips your license and grant keys, so a copied query is safe to paste into notes, a ticket, or an AI chat.
  • Refresh the JobTread tab with the panel open and it reconnects on its own — no need to close and reopen.
  • Want your AI to read these queries back later? That's the separate “Record for AI” toggle on this tab (Power User), which feeds stripped queries to your AI through the MCP.
