Auto Sequence.

Dragging a schedule item changes its dates. It does not change its place in the list — which is why your Gantt bars end up marching backwards.

Video walkthrough coming soon

What it does

JobTread tracks a schedule item's dates and its manual sequence as two separate things. Drag an item to a new week and the dates move; the sequence stays exactly where it was. Do that a few dozen times over a live job and the Gantt reads like a staircase going the wrong way, with someone eventually hand-dragging thirty rows back into order.

Auto Sequence adds a button to the schedule's mass-actions panel. One click re-orders the items inside each group so the list runs in the same order as the work — earliest start first.

Turn it on

  1. Click the JT Power Tools icon in your browser toolbar.
  2. Find Auto Sequence under Schedule & Calendar.
  3. Flip the toggle on. No reload needed.

How to use it

  1. Open the job's Schedule.
  2. Open the mass-actions panel — the same one you use for bulk edits.
  3. Click Auto Sequence. It reads the tasks, works out what needs to move, and commits the new order.

Good to know

  • Dates are never written. The only thing that changes is each item’s position in its group, so a resequence cannot shift a date, push a deadline, or set off a dependency cascade.
  • Your phases stay put. Top-level groups are never re-ordered — that order is your process, not a function of dates. Only the items inside each group move.
  • Items cannot jump between groups. Sequence is scoped to an item's parent, so re-ordering inside a group physically can't move something out of it.
  • You set the connection up once. Auto Sequence works through JobTread's API rather than the page, so it needs a grant key, and a grant key lives in a JT Power Tools account. Both are free: sign up without a licence key and you get a free-tier account that can hold one. It is the same connection the rest of the API-backed features run on — Budget Changelog, Invoice Forecast, Editable Tables, Unassigned Availability, Worksheets — so this is the only time you do it. Without a key Auto Sequence tells you so and links you straight to where it goes, instead of failing quietly.
