Power User

Job switcher filter.

Filter the Job Switcher by any custom field you've set up — project manager, region, job type, status. Find the right job in seconds, even with hundreds active.

Video walkthrough coming soon

What it does

Press J+S to open the Job Switcher. Now there's a filter dropdown that pulls in your custom field values from JobTread. Pick "PM = Sarah" or "Type = Remodel" and the list narrows. Type to search inside that filtered list. The data is cached so it stays fast.

Turn it on

  1. You need a JobTread Grant Key — set this up under Account on the popup first.
  2. Make sure Smart Resize (Job Switcher) is on.
  3. Find Job Switcher Filter under Productivity Tools and flip it on.

How to use it

  1. Press J then S to open the Job Switcher.
  2. Use the filter dropdowns to pick your custom field criteria.
  3. Type in the search box to narrow further.
  4. Press Enter to jump to the highlighted job.

Good to know

  • Set up meaningful custom fields in JobTread before turning this on — there's nothing to filter without them.
  • Common setups: filter by PM, by region, by job stage, by job type.
  • Filters reset when you close the switcher; saved searches are on the roadmap.
