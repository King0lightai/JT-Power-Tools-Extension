Print Scope.

Print the scope you're already looking at. No saving a document you didn't want just to get it on paper.

Video walkthrough coming soon

What it does

Select line items in a budget and JobTread renders them as a scope document in a Preview Document modal. It looks right, it reads right — and there is no way to print it. To get a printed scope you have to create a real document first, which leaves a record nobody asked for on the job.

Print Scope adds a Print button to that modal, plus a font-size picker. Click it and you get the scope as it appears on screen, printed or saved as a PDF, with nothing written back to the job.

Turn it on

  1. Click the JT Power Tools icon in your browser toolbar.
  2. Find Print Scope under Documents & Text.
  3. Flip the toggle on. No reload needed.

How to use it

  1. Open a job's budget and select the line items you want in the scope.
  2. Choose Preview Document and pick a template, the same as always.
  3. Click Print in the modal. Set the size first if you want bigger type.
  4. Your browser's print dialog opens — print it, or save it as a PDF.

Good to know

  • Three type sizes — normal, large, and larger. The picker scales the printed copy only; the modal on screen never changes. Your choice is remembered on that browser.
  • The printed copy is built in an isolated frame using JobTread's own stylesheets, so it matches what you saw on screen instead of arriving clipped by the modal or shaded by the grey backdrop.
  • Nothing is created, saved, or sent. If you weren't going to keep the document, you still don't have to.
