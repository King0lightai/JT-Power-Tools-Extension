The MCP Server

An Model Context Protocol server that gives any AI assistant — Claude, ChatGPT, Cursor, Gemini, Copilot — direct read-write access to your JobTread data. Hosted on Cloudflare Workers, multi-org by default, with permission tiers so the AI only sees what it should.

Claude · ChatGPT · Cursor Cloudflare Workers Permission tiers
  • Rich context tools. Single calls return a job + budget + schedule + documents + activity together — no manual stitching, no context bloat.
  • Full write surface. Create jobs, tasks, comments, daily logs, cost items, time entries, documents, payments, and webhooks — every safe op exposed.
  • Context-mode indexing. Big payloads get auto-indexed into an FTS5 knowledge base so the AI can recover details after compaction — up to 98% context savings.
  • Multi-org safe. Per-org grant keys mean a single AI client can switch between organizations without crossing the streams.

04 / 06

The Vendor Bills Inbox

Vendors email their invoices to a forwarding address. PDFs are parsed and queued. An AI agent reads each one, matches the job and vendor, finds any open PO, and posts the bill into JobTread with the right cost coding and QBO routing. Your AP clerk reviews — they don't re-type.

Email forwarding PDF parsing QBO routing
  • Forward-and-forget. Approved-sender allowlist keeps junk out. Every PDF lands in your inbox queue, waiting for AI review.
  • AI matches everything. Job (from the PO marker), vendor (from the letterhead), open POs, and cost codes — all resolved before the bill posts.
  • QBO routing built in. Bills vs. card purchases land in the right QBO document type. Bank/CC account, billable flag, ignore flag — all controllable per-bill.

Tweaks & Forms

For teams who want to go further. Tweaks let admins ship custom CSS to every team member's browser — change spacing, colors, or hide UI you never use. Forms turn JobTread into a real intake engine — custom forms, custom validation, structured submissions.

Custom CSS tweaks Form templates Sanitized + scoped
  • Org-published, user-toggleable. Admin publishes a tweak once; every team member sees it instantly with the option to opt out per machine.
  • Safe by default. Tweak CSS is sanitized server-side. No javascript: URIs, no expression(), no escape hatches.
  • Forms with teeth. Build intake forms with conditional fields and validation. Submissions land in the portal and can post back into JobTread as comments, tasks, or jobs.
