Quick answers.

The extension stopped working after a JobTread update

JobTread occasionally ships UI changes that break class-name selectors the extension relies on. Update to the latest version from the Chrome Web Store — fixes usually ship within a day or two. If it's still broken, email support with a screenshot.

How do I report a bug or request a feature?

Open an issue on GitHub. Include what you expected, what happened, and which JobTread page you were on. Screenshots help. If you'd rather keep it private, email support.

I lost access to my premium features

Sign into the account portal to verify your subscription. If the license is active but features are still locked, try removing and re-adding the extension, then sign in again from the popup. Still stuck? Email support with your account email.

Can I use JT Power Tools on multiple computers?

Yes. Install the extension on each browser and sign into the same account. Your settings sync automatically through Chrome's storage API.

Do I need a JobTread account?

Yes — JT Power Tools is a browser extension that enhances the JobTread web app (app.jobtread.com). It doesn't replace JobTread; it makes it better.

Is my data secure?

The extension runs entirely in your browser. It never proxies JobTread data through our servers. Account info (email, subscription status, team membership) is stored in our database. See the privacy policy for specifics.

How do I cancel my subscription?

Sign into the account portal and manage your plan there. You'll keep premium access through the end of the current billing period.
