v4.7.0 Current April 28, 2026

✨ New Features

  • User Tweaks — Bring-Your-Own UI Customization (Pro)
    • Author small declarative customizations of the JobTread UI — CSS rules + a closed list of DOM verbs (addClass, removeClass, setStyle, hide, show, setText, onEvent) — that apply automatically when you visit JobTread
    • New Tweaks tab in the popup: list, toggle, edit, and delete with one click
    • Standalone editor at chrome-extension://<id>/tweaks/edit.html with live JSON validation, CSS warnings, and "test on active JT tab" dry-run that shows per-selector match counts
    • Server-backed storage with full version history — every save creates an immutable version row so you can roll back anytime
    • Defense-in-depth: server-side AST sanitizer rejects @import, expression(), unsafe url(), and bare html/body/* selectors. Auto-scopes every selector to .jt-tweak-{id} so a tweak's styles can't bleed outside its own elements
  • Org-Required Tweaks — Push Tweaks to Your Whole Company (Admin)
    • Admins can mark a tweak as "Required for Org" — it gets pushed to every member of your JobTread organization automatically
    • Members see a purple "Required" badge on org-pushed tweaks; Edit/Delete buttons hidden (admin-managed)
    • Local-disable hatch: members can toggle off org-required tweaks on their own device only — admin sees aggregate override counts (never which specific member opted out)
    • Portal admin page at app.jtpowertools.com → Tweaks tab: list, create, edit, and delete org-required tweaks. New audit panel shows "X of Y members have locally disabled this tweak" so admins can spot underused or annoying tweaks
    • Scope flips allowed (Personal ↔ Required for Org) — admins can promote a useful personal tweak to org-wide without losing version history
  • Inspect-for-AI — Right-Click Capture for AI Authoring (Pro)
    • Alt-click any element on JobTread (or activate Picker mode from the popup) to capture a structured markdown description of that element — CSS selector, ancestor chain, sample of nested elements, current page path, and your JobTread organization name
    • Captured payload copied straight to your clipboard so you can paste it into your AI assistant (Claude, ChatGPT, Cursor, etc.) and get back a working tweak JSON to paste into "Paste from AI"
    • Multi-view picker mode: switch JobTread views between captures (table → Gantt → month) and produce one combined AI prompt that covers them all
    • Keyboard shortcuts: Alt+Shift+P to start single picker, Alt+Shift+M for multi-view
    • Captures stay 100% local — never transmitted to our servers, only written to your clipboard for you to paste
  • MCP Permission Tiers — Admin-Controlled AI Access (Power User)
    • Three-tier permission model per AI grant key: Read (query data only), Read + Write (also create/update records), Read + Write + Delete (full access including destructive ops)
    • New AI grant keys default to Read (least privilege) — admin explicitly opts each key up to write or delete via the portal
    • Existing AI grant keys grandfathered to full access (Read + Write + Delete) so current AI clients keep working unchanged. Admin can downgrade individual keys at any time
    • Inline Permission column on the AI Grant Keys table in the portal — change tiers per-key with one click, no modal needed
    • License-level default picker — set what new keys inherit, never affects existing keys
    • Op-level enforcement: jt_job_write's delete op requires Delete tier even if the key has Read+Write — fine-grained protection without a separate tool
  • 5 New MCP Tools for AI Tweak Authoring (Power User)
    • jt_list_tweaks + jt_get_tweak — AI can inspect existing tweaks (Read tier)
    • jt_create_tweak + jt_update_tweak + jt_revert_tweak — AI can author and roll back tweaks (Write tier)
    • AI-authored tweaks are attributed to the admin who issued the AI key, not anonymized — so the popup shows real ownership instead of "via AI key"
    • Same defense-in-depth as the popup: server validates DSL + sanitizes CSS on every AI-driven write

🔧 Improvements

  • Server-Backed Storage Replaces Local-Only
    • Tweaks now sync across your devices and persist when you reinstall the extension — they live on our servers, not just in browser storage
    • Offline-friendly: extension reads from a local cache first, refreshes from server in the background. If our servers are unreachable your tweaks still work
    • Engine telemetry (selector match counts, last error) flushes to the server periodically so the popup can show "no matches found" warnings even if you switch devices
  • Privacy Policy Refresh
    • Updated to disclose User Tweaks server storage, MCP write capabilities + permission tiers, and the Inspect-for-AI clipboard flow
    • Replaced the outdated "MCP is read-only" claim with the accurate three-tier model
    • Made explicit that AI prompt content is never seen by our servers (we proxy structured tool calls only) and DOM captures from Inspect-for-AI never leave your clipboard

🐛 Bug Fixes

  • Editor Scope Toggle Now Works for Admins
    • Three independent bugs were combining to make the Personal ↔ Required for Org radio appear interactive but never actually save the change
    • Fixed a CSS leak that left the toggle visible to non-admins, an AccountService init race that mis-marked owners as non-admins, and a save-time admin gate that compounded the race
    • Admins can now flip an existing personal tweak to org-required (or back) without deleting and re-creating
  • Re-Adding a Deleted Tweak No Longer Errors
    • Deleting a tweak then pasting the same JSON back used to fail with a database constraint error
    • Server now resurrects soft-deleted tweaks on re-create with the same id — version history preserved, no duplicate-id collision
